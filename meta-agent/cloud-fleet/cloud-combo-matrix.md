# Cloud-Combo Matrix

Authoritative matrix of common cross-cloud Salesforce sales/solution combinations. Owned by `salesforce-cloud-router`. Cloud-experts NEVER edit this file directly — they file proposals to `personifier/personas/<slug>/refresh/log/<YYYY-MM-DD>-proposed-combos.md` (per FD8).

The router's quarterly sweep validates and merges proposals into this matrix.

**Schema (one row per combo):**

| Combo name | Primary cloud(s) | Secondary cloud(s) | Trigger signature | Pattern doc URL | Last validated | Confidence |
|---|---|---|---|---|---|---|

**Confidence bands:** `high` (validated by ≥ 3 customer engagements or product-team-blessed pattern doc), `medium` (validated by ≥ 1 engagement or community-blessed), `low` (proposed but not yet validated).
